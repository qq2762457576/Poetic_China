云端连接自检

填好 URL 和密钥后点「开始自检」，会逐项测试连通性并给出具体错误。
这个页面只在你本机运行，输入的内容不会上传、不会保存到仓库。

① 去哪里找这两个值

Project URL —— 你已经找到了，形如 https://abcdefgh.supabase.co。
新版界面里它在 Project Settings → Data API（旧版这个菜单叫 API，Supabase 改名了，所以按老教程找不到）。

密钥在哪 —— 三个地方找，总有一个能看见：

  1. 同一个 Data API 页面，往下滚动，找 Project API keys 区域
  2. 左侧 Project Settings 下有独立一项 API Keys（新版把密钥单独拆出来了）
  3. 页面右上角绿色 Connect 按钮 → App frameworks 标签 → 直接列出 SUPABASE_ANON_KEY

密钥长这样，两种格式都能用：

  • 新版：sb_publishable_xxxxxxxxxxxx
  • 旧版：eyJhbGciOi...（一长串，通常 100 字符以上）

如果看到好几条，认准带 anon 或 publishable 字样的那一条。

⚠️ 千万不要复制 service_role / secret 那一条。它是管理员密钥，放进前端等于把数据库权限公开。要的是 anon / publishable。
